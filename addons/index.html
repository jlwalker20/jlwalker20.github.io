WoW Forever AddOns

Tap a file to download. Each addon needs its .toc and .lua in a folder of the same name inside Interface/AddOns/. Tap README to read how it works.

Install: make a folder named after the addon (for example FlightTimer), put both downloaded files in it, and place the folder in Interface/AddOns/ in your WoW Forever game folder. Then /reload or restart the game. Each README has the full steps.

ShortChannelsv1.1

Shortens chat channel names: General becomes G, Trade becomes T, Trade (Services) becomes TS, Trade (Local) becomes TL, and so on.

.toc .lua README

ChatFadev1.0

Fades the chat window after 30 seconds without a new message and brings it back when one arrives, including on zone changes.

.toc .lua README

ShowTotemBarv1.0

Keeps the Shaman totem bar visible in gamepad mode so it shows up in Edit Mode.

.toc .lua README

FlightTimerv1.4

Countdown for your current flight path, lower-middle of the screen. Learns each route the first time you fly it. Movable, with macros for gamepad mode.

.toc .lua README

Beta AddOns for the WoW: Forever client 1.60.1 (70170). In gamepad mode, run addon commands from macros instead of typing in chat; the READMEs explain which macros each addon creates. File paths are case-sensitive: files live under /AddOns/<Name>/ on this site.
