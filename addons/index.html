WoW Forever Addons

Tap a file to download. Each addon needs all of its files in a folder of the same name inside _forever_/Interface/AddOns/ in your game folder. DarkIronUI comes as one zip because it has many files. Tap README to read how it works.

Download all addons (.zip)

One zip with every addon below, already in its own folder. Steam Deck: open Downloads in Dolphin, right-click the zip, choose Extract → Extract archive here, then drag the folders into _forever_/Interface/AddOns/ (replace when asked). PC: right-click, Extract All, and drag the same way.

Install: make a folder named after the addon (for example FlightTimer), put its downloaded files in it, and place the folder in _forever_/Interface/AddOns/ in your WoW Forever game folder. Then /reload or restart the game. Each README has the full steps.

Look

A full dark-grey reskin of the default UI, plus reshaped cast bars.

DarkIronUIv1.16

Recolors the default UI from gold and brown to a consistent dark grey: unit frames, gamepad and keyboard action bars, XP bar, bag bar, menu bar, cast bars, minimap, quest tracker and tooltips. Icons, bar colors and quality colors stay as they are. Every part can be toggled on its own. Replaces FlatUnitFrames and GamepadDarkMode; delete those first.

DarkIronUI.zip README Single parts (.zip)

CastBarPlusv0.8

Makes your cast bar taller and puts the spell name inside the bar, centered, with the cast timer on its right edge. The border keeps its proportions instead of stretching.

.toc .lua README

TargetCastBarPlusv0.10

The same look for your target's and focus's cast bars: taller, with the spell name and a cast timer inside the bar and the spell icon centered beside it. The bars sit above their frames, drawn in front of the buff icons; switch each one back below with the TCB Target and TCB Focus macros.

.toc .lua README

SquareMinimapv0.6

Makes the minimap square with a border built from Blizzard's own frame pieces (Diamond metal, Dialog edge and more; /sqm style), tinted to match DarkIronUI. Keeps the north arrow on the top edge and lines the zoom buttons up under the bottom-right. Test version.

.toc .lua README

Quality of life

Small fixes for chat, party frames, travel and gathering.

ShortChannelsv1.4

Shortens chat channel names: General becomes G, Trade becomes T, Trade (Services) becomes TS, Trade (Local) becomes TL, and so on.

.toc .lua README

ChatFadev1.1

Fades the chat window after 30 seconds without a new message and brings it back when one arrives, on zone changes, or when you open the input box.

.toc .lua README

TargetClassColorsv0.3

When you target another player, the target frame's health bar turns their class color. NPCs keep Blizzard's normal colors.

.toc .lua README

PartyFramesImprovedv2.9

Everything for Blizzard's raid-style party and raid frames: party frames stack from the bottom up with you on top and everyone else in class order; raid frames grow from the bottom-right in the same order, with "Keep Groups Together" on or off; levels on names; leader crown and target marker on the health bar; the top-left shows the faction icon (gray until PvP-flagged), the role icon, or nothing (/pfi slot); incoming heal and shield bars that run past the frame's edge. Replaces PartyGrowUp, PartyLevels and DispelGlow. Commands: /pfi help.

PartyFramesImproved.zip README

QuestMarksv0.6

Puts a small yellow * after the nameplate name of mobs your active quests still need, whether you have to kill them or they drop a quest item.

.toc .lua README

FlightTimerv1.4

Countdown for your current flight path, lower-middle of the screen. Learns each route the first time you fly it. Movable, with macros for gamepad mode.

.toc .lua README

GatheringLevelsv0.3

Shows each zone's Herbalism, Mining, Skinning and Fishing skill ranges on the world map, only for the professions you have, colored by your current skill. Needs all three files.

.toc Data.lua .lua README

HideChatButtonsv0.2

Hides the social, chat channels and chat menu buttons on the left side of the chat window, and the dark strip behind them. Voice and scroll buttons can be hidden too.

.toc .lua README

WeakenedSoulTrackerv0.6

For priests: a cooldown-style icon for everyone you shield, with their portrait, class-colored name and a countdown until Weakened Soul ends. Works in combat (it tracks your casts, not auras). Movable in Edit Mode, three saved spots for solo, party and raid. Commands: /ws help.

.toc .lua README

Gamepad

For playing with a controller (Steam Deck, Xbox pad).

ShowTotemBarv1.1

Keeps the Shaman totem bar visible in gamepad mode so it shows up in Edit Mode.

.toc .lua README

HideCrosshairsv0.7

Hides the red and green "Target Modifier" crosshair icons above the gamepad action bars. Your bumper bindings still work.

.toc .lua README

HideChatLegendv0.2

Hides the gamepad button legend (Send / Chat Channels / Tab Settings / Back) that pops up under the chat box while you type. The buttons still work the same.

Addons for WoW: Forever, client 1.60.1 (live build 70790). Moving from the beta? Copy them into the new _forever_ folder; settings from the beta don't carry over. In gamepad mode, run addon commands from macros instead of typing in chat; the READMEs explain which macros each addon creates. File paths are case-sensitive: files live under /addons/<Name>/ on this site.
