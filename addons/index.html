WoW Forever Addons

Tap a file to download. Each addon needs all of its files in a folder of the same name inside Interface/AddOns/. DarkIronUI comes as one zip because it has many files. Tap README to read how it works.

Download all addons (.zip)

One zip with every addon below, already in its own folder. Steam Deck: open Downloads in Dolphin, right-click the zip, choose Extract → Extract archive here, then drag the folders into Interface/AddOns/ (replace when asked). PC: right-click, Extract All, and drag the same way.

Install: make a folder named after the addon (for example FlightTimer), put its downloaded files in it, and place the folder in Interface/AddOns/ in your WoW Forever game folder. Then /reload or restart the game. Each README has the full steps.

Look

A full dark-grey reskin of the default UI.

DarkIronUIv1.6

Recolors the default UI from gold and brown to a consistent dark grey: unit frames, gamepad and keyboard action bars, XP bar, bag bar, menu bar, buffs and debuffs, nameplates, minimap, quest tracker and tooltips. Icons, bar colors and debuff-type colors stay as they are. Every part can be toggled on its own. Replaces FlatUnitFrames and GamepadDarkMode; delete those first.

Quality of life

Small fixes for chat, frames, travel and gathering.

ShortChannelsv1.2

Shortens chat channel names: General becomes G, Trade becomes T, Trade (Services) becomes TS, Trade (Local) becomes TL, and so on.

.toc .lua README

ChatFadev1.1

Fades the chat window after 30 seconds without a new message and brings it back when one arrives, on zone changes, or when you open the input box.

.toc .lua README

TargetClassColorsv0.1

When you target another player, the target frame's health bar turns their class color. NPCs keep Blizzard's normal colors.

.toc .lua README

PartyLevelsv1.0

Adds each member's level to their name on the raid-style party and raid frames, colored by difficulty like the target frame.

.toc .lua README

FlightTimerv1.4

Countdown for your current flight path, lower-middle of the screen. Learns each route the first time you fly it. Movable, with macros for gamepad mode.

.toc .lua README

GatheringLevelsv0.3

Shows each zone's Herbalism, Mining, Skinning and Fishing skill ranges on the world map, only for the professions you have, colored by your current skill. Needs all three files.

.toc Data.lua .lua README

Gamepad

For playing with a controller (Steam Deck, Xbox pad).

ShowTotemBarv1.1

Keeps the Shaman totem bar visible in gamepad mode so it shows up in Edit Mode.

.toc .lua README

HideCrosshairsv0.7

Hides the red and green "Target Modifier" crosshair icons above the gamepad action bars. Your bumper bindings still work.

.toc .lua README

HideChatLegendv0.2

Hides the gamepad button legend (Send / Chat Channels / Tab Settings / Back) that pops up under the chat box while you type. The buttons still work the same.
